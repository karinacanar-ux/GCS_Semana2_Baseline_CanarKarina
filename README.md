# MediConnect — Depósito de Configuración

Práctica de la Semana 2 de Gestión de la Configuración del Software.

## Objetivo
Organizar los elementos iniciales del proyecto y registrar la primera línea base: **LB-001**.

## Estructura
- `docs/`: documentación.
- `src/`: código fuente.
- `config/`: configuración de ejemplo.
- `database/`: scripts SQL.
- `tests/`: casos de prueba.
- `evidencias/`: capturas de la práctica.
