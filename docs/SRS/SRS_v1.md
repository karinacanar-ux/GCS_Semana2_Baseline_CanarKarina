# Especificación de Requisitos de Software

**Proyecto:** Aplicación para la gestión de cobranzas en campo  
**Versión:** 1.0  
**Estado:** Candidato a línea base  
**Fecha:** 26 de julio de 2026  

## 1. Objetivo

Definir los requisitos iniciales de una aplicación orientada al registro, consulta y priorización de cobranzas en campo para Dermafreya S. A.

## 2. Requisitos funcionales

### REQ-001 – Consulta de cartera

El sistema deberá permitir consultar los clientes que mantienen valores pendientes de cobro.

### REQ-002 – Priorización de cobranzas

El sistema deberá clasificar las cobranzas según los días de mora y el valor pendiente.

### REQ-003 – Registro de gestiones

El sistema deberá permitir registrar la fecha, el tipo y el resultado de cada gestión de cobro.

### REQ-004 – Registro de compromisos

El sistema deberá permitir registrar compromisos de pago con su valor, fecha acordada y estado.

## 3. Requisitos no funcionales

### REQ-005 – Rendimiento

El sistema deberá mostrar las consultas principales en un tiempo máximo de tres segundos, bajo condiciones normales de operación.

### REQ-006 – Seguridad

El sistema deberá solicitar autenticación y controlar el acceso a las funciones según el rol asignado al usuario.

## 4. Criterio de aprobación

Los requisitos REQ-001 a REQ-006 serán considerados aprobados para conformar la línea base v1.0 una vez revisados y versionados en el repositorio.
